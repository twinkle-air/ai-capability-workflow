# Agent 设计要点

适用于需要持续达成目标、使用工具并处理中间状态的任务。

在实现前写清：

- **目标与完成条件：** 哪些结果可直接观察，什么情况算失败。
- **观察与行动：** 可访问的数据和工具、每种工具会改变什么。
- **权限：** 读写边界、外部副作用、需要单独授权的动作。
- **状态：** 哪些信息必须跨步骤保存，如何恢复中断任务。
- **停止条件：** 完成、超时、预算耗尽、重复错误、缺少授权分别怎么处理。
- **人与 Agent 的交接：** 哪些决策交还用户，交接时要附什么证据。

先实现一条可观察的最短执行路径，再增加规划、记忆、并行或其他 Agent。复杂度只能由验证中出现的真实需求驱动。至少验证一次工具失败、一次信息不足、一次权限不足以及一次中断恢复。记录每次动作的输入、结果和状态变化，便于定位错误。
