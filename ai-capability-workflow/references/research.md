# 资料检索与取舍

## 检索范围

从用户目标拆出主题：任务领域、目标平台、实现方法、数据、评估方法与风险。对每个主题记录关键词、同义词、检索站点或数据库、时间范围、检索日期。沿关键文献的引用和后续引用补查，直到新增资料不再改变主要设计决策；记录仍未覆盖的领域。

## 证据判定

| 检查项 | 处理方式 |
| --- | --- |
| 来源身份 | 优先原始论文、正式标准、官方文档/数据；无法确认出处则不采用 |
| 时效 | 软件接口与平台规则核对当前版本；旧资料保留日期与适用版本 |
| 方法 | 记录样本、实验条件、限制；不能把局部实验推广为通用事实 |
| 一致性 | 重要结论与独立来源交叉核查；冲突时保留分歧及采用理由 |
| 可追溯 | 保存标题、作者/机构、链接或 DOI、日期、所支持的清单项 |
| 使用权 | 下载或嵌入资料、样本前核对许可、隐私和再分发条件 |

研究笔记和来源记录应明确区分“证据支持”“合理推断”“待确认”。没有可靠资料支持的关键输入，回到用户澄清或缩小功能，不用猜测填补。
